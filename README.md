# Yukari MangaLivre Plugin

A MangaLivre source plugin for Yukari, allowing users to browse and read manga from MangaLivre.

## Features

- Search for manga
- View manga details and cover images
- Browse chapter lists
- Read manga chapters
- Browse the latest updates
- Navigate through paginated search results

## Download

**[Download the latest release](https://github.com/FrightV/Yukari.Plugin.MangaLivre/releases)**

Download the plugin `.dll` file from the **Assets** section of the latest release.
